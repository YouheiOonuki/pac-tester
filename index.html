PAC ファイル テスター

proxy.pac の FindProxyForURL を URL の一覧でまとめてテスト。構文チェックと新旧の差分比較つき。

ダウンロードして使う（無料）

本体は pac-tester.html という 1 つのファイルです。インストール不要・通信しないので、ソフトを入れられない職場の PC やネットにつながらない環境でも使えます。

ダウンロード（pac-tester.html・約 370KB） ブラウザで試す

「ブラウザで試す」は、ダウンロードするものと同じファイルを開きます。

使い方（3 ステップ）
  1. 上の「ダウンロード」で pac-tester.html を保存して、ダブルクリックで開く
  2. 左の欄に PAC を貼り付ける（.pac ファイルをドラッグ＆ドロップしても開けます）
  3. 右の欄にテストしたい URL を 1 行に 1 つ書く。入力するたびに自動で評価され、結果の表とチェックの結果が出ます

はじめて開くと、架空のドメインを使った見本の PAC と URL の一覧が出ます。

できること

URL の一覧でまとめて評価、標準のヘルパー関数（isInNet・shExpMatch など 14 個）、構文・ロジックのチェック、差分モード。

くわしく
  • URL の一覧でまとめて評価：1 行に 1 つの URL を並べると、それぞれの戻り値（DIRECT・PROXY host:port; …）を表にします。ホスト名は URL から自動で取り出します
  • 戻り値ごとに色分け・絞り込み・CSV 保存：alert() の出力、エラー、タイムアウトも行ごとに出します
  • 標準のヘルパー関数：isInNet・shExpMatch・dnsDomainIs・weekdayRange・timeRange など 14 個。DNS の代わりに「ホスト名と IP アドレスの対応表」、myIpAddress() の値、評価に使う日時を自分で決められます
  • 構文・ロジックのチェック：全角スペースや全角記号の混入（コメントの中は除く）、括弧・引用符の対応、最後の return 漏れ、shExpMatch のパターンの誤り（* の付け忘れ、スキーム付きなど）、上のルールが下のルールを隠しているケースを見つけます
  • 差分モード：旧 PAC と新 PAC を同じ URL の一覧で評価し、結果が変わった URL だけを強調します。更新のたびに「意図した変更だけが起きているか」を確かめられます
  • 無限ループでも固まらない：1 つの URL につき 0.2 秒で打ち切ります

貼った PAC は外に出ない・隔離して実行する

外部のサーバーには一切接続しません。PAC は隔離した枠（sandbox の iframe）の中の Worker で実行します。

くわしく
  • pac-tester.html は、構文を調べるライブラリ（acorn）も含めて 1 ファイルの中に入っています。外部のサーバーには一切接続しません（ブラウザの仕組み Content-Security-Policy でも通信を禁止しています）。社内のホスト名が入った PAC でも、どこにも送られません
  • PAC は JavaScript のプログラムなので、ページとは別の、隔離した枠（sandbox の iframe）の中の Worker で実行します。PAC のコードからは、このページの画面や保存領域には触れられず、通信もできません
  • 貼った PAC は、既定ではブラウザにも保存しません（保存するかどうかは自分で選べます）
  • pac-tester.html には広告やアクセス解析は入っていません（広告はこの紹介ページと使い方ページだけです）
